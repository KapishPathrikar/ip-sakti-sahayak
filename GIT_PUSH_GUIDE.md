## 🚀 **Push Commands**

### **Option 1: First Time Push (New Branch)**
```bash
# Check current status
git status

# Add all new files
git add DEVELOPMENT_REPORT_2026_08_28.md
git add NEXT_STEPS_CHECKLIST.md
git add test_backend.py
git add backend/.env
git add backend/rag/cloud_llm.py
git add backend/rag/generate_modified.py
git add requirements_backend.txt
git add README.md

# Or add all changes (be careful of unwanted files)
git add .

# Create commit with descriptive message
git commit -m "feat: Backend setup complete with Cloud LLM support

- Complete backend environment setup
- Added Cloud LLM integration (Together.ai, OpenRouter, Groq)
- Created comprehensive test suite with Postman collection
- Updated documentation with deployment options
- Added development report and next steps checklist
- Enhanced error handling and fallback mechanisms

Date: 2026-08-28"

# Create new branch (recommended)
git checkout -b backend-setup-complete

# Push to remote
git push -u origin backend-setup-complete
```

### **Option 2: Update Existing Repository**
```bash
# Pull latest changes first
git pull origin main

git add .
git commit -m "chore: Update backend setup and documentation

- Added alternative LLM deployment options

# Or create PR from feature branch

```

## 🎯 **Commit Message Guidelines**

### **Format**
```
type: Short description (50 chars or less)

Longer description if needed. Wrap at 72 characters.
Explain what and why, not how.

- Bullet point for key changes
- Another bullet point if needed
- Reference issues or tickets

Date: YYYY-MM-DD
```

### **Types**
- `feat`: New feature
- `fix`: Bug fix  
- `docs`: Documentation changes
- `style`: Code style/formatting
- `refactor`: Code restructuring
- `test`: Test additions/modifications
- `chore`: Maintenance tasks

## 🛠️ **Troubleshooting**

### **Common Issues**
1. **Permission denied**
   ```bash
   # Check remote URL
   git remote -v
   
   # If using HTTPS, may need personal access token
   git remote set-url origin https://github.com/KapishPathrikar/ip-sakti-sahayak.git
   ```

2. **Large files rejected**
   ```bash
   # Check for large files
   git ls-files | xargs wc -l | sort -n
   
   # Remove large files if not needed
   git rm --cached large_file.bin
   ```

3. **Merge conflicts**
   ```bash
   # Pull latest changes
   git pull origin main
   
   # Resolve conflicts manually
   # Then add and commit
   git add .
   git commit -m "fix: Resolve merge conflicts"
   ```

### **Git Commands Reference**
```bash
# View changes
git diff

# View staged changes
git diff --staged

# View commit history
git log --oneline -10

# Undo last commit (keep changes)
git reset --soft HEAD~1

# Undo last commit (discard changes)
git reset --hard HEAD~1

# Check remote branches
git branch -r
```
